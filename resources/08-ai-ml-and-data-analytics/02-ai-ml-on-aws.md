# AI/ML on AWS

## Objectives

- Spot common AI/ML business uses.
- Name the AWS AI/ML stack's three tiers.

## Notes

### Use cases

- Amazon uses ML for recommendations and fulfillment.
- ML predicts (stock trends, prices of goods), decides (routing a caller by spoken request) and detects anomalies (online-banking fraud).

### The three tiers

- AI services: managed, pre-trained models for set jobs, such as Amazon Polly (text to speech) and Amazon Comprehend (text and sentiment).
- ML services: for more customization, you create, train and ship custom models in Amazon SageMaker AI while AWS manages infrastructure, tools and workflows, with experiments, data visuals, debugging and monitoring in one place.
- ML frameworks and infrastructure: fully custom work for specialized needs, on purpose-built chips with popular frameworks or ML-optimized EC2.

## Key takeaways

- ML predicts, decides and detects anomalies.
- Tiers run from ready-made (AI services) to your own models (SageMaker AI) to fully custom.
- SageMaker AI is the main ML services example.

## Terms

- **AWS AI/ML stack**: AI services, ML services, and ML frameworks and infrastructure.
- **Amazon SageMaker AI**: Fully managed service where you create custom ML models.
