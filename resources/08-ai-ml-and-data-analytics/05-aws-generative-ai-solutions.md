# AWS Generative AI Solutions

## Objectives

- Explain what each AWS generative AI service is for.

## Notes

### Services

| Amazon service | Is | Uses |
| --- | --- | --- |
| SageMaker JumpStart | Hub in SageMaker AI; vision, NLP, tabular solutions to fine-tune and deploy in clicks | Deploys without expertise, domain fine-tuning, model comparison |
| Bedrock | Managed FMs from Amazon and startups (Claude, Stable Diffusion) via one API; test, tune, integrate | Secure, private, scalable production apps; text and image output; agents on company data |
| Q Business | Fields questions, fixes problems, runs tasks from company repositories over secure links | Information requests, workflows, insights |
| Q Developer | Suggests code, even whole functions and logical blocks, in multiple IDEs; languages include C#, Java, JavaScript, Python, TypeScript | Faster coding, reliability, security, code reviews |

- Amazon Q streamlines work, speeds decisions and lifts productivity with insights and faster tasks.
- Managed, enterprise-grade multimodal generation points to Bedrock, not JumpStart or Q Business.

## Key takeaways

- JumpStart: fast model starts in SageMaker AI.
- Bedrock: many managed FMs, one API.
- Q Business serves staff; Q Developer serves coders.

## Terms

- **Amazon SageMaker JumpStart**: SageMaker AI model hub.
- **Amazon Bedrock**: Managed FMs, one API.
- **Amazon Q Business**: Company-data assistant.
- **Amazon Q Developer**: Coding assistant.
- **Fine-tuning**: Adapting a pre-trained model with your data.
- **Multimodal**: Generating several content types.
