# Additional Security Resources

## Objectives

- Find security help and tools.

## Notes

### Docs

- Each service differs, so read its docs.
- [Security, Identity, and Compliance on AWS](https://aws.amazon.com/products/security/): overview.
- [Knowledge Center](https://repost.aws/search/content?globalSearch=security): Q&A, troubleshooting.
- [AWS Security Documentation](https://docs.aws.amazon.com/security/): by product.
- [AWS Security Blog](https://aws.amazon.com/blogs/security/): expert tips.
- **Exam guide update** (verified_on 2026-10-09, [Overview of AWS: Security and compliance](https://docs.aws.amazon.com/whitepapers/latest/aws-overview/security-and-compliance.html)): AWS Security Center is the name AWS documentation gives the cloud security site at aws.amazon.com/security, where it points you for more on AWS security and compliance.

### AWS Marketplace

- Sells third-party software and services for AWS, like [security tools](https://aws.amazon.com/marketplace/solutions/security):
  - Threat detection and prevention: stop attacks.
  - Identity and access management: permissions, login.
  - Data protection: encryption.
  - Compliance and governance: regulations.

## Key takeaways

- Read each service's docs.
- Sources: overview, Knowledge Center, docs, blog.
- Marketplace tools: threat, identity, data, compliance.

## Terms

- **AWS Marketplace**: A third-party software store.
