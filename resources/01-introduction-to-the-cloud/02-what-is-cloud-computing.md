# What is Cloud Computing?

## Objectives

- State what cloud computing means.
- Compare the deployment types.

## Notes

### From Amazon.com to AWS

- Amazon.com, then selling books and other goods, kept scaling its servers, and in 2003 planned to rent such resources out on demand, which could spare others upfront hardware costs.
- Amazon Simple Queue Service (November 2004) was the first public infrastructure service, with Amazon S3 and Amazon Elastic Compute Cloud two years later.
- Start-ups and developers came first, then enterprises drawn by scalability, cost and ease of use, and with databases, networking and analytics added, AWS now powers much of the internet as a global leader.

### The definition, part by part

- **On-demand delivery**: resources in seconds, scaled up or down without long setup, the idea AWS began with.
- **IT resources**: servers, storage, databases, networking, AI/ML tools and more, to build and run applications.
- **Over the internet**: remote use through web-based services, not local hardware, from anywhere.
- **Pay-as-you-go pricing**: pay for consumption, not fixed long-term contracts, for cost efficiency and flexibility.

### Data centers

- A data center is one or more buildings of servers with redundant power, cooling and security.
- Firms once ran their own or co-located, but AWS lets them use data centers they do not own, trading upkeep and repetitive chores for innovation.

### Cloud deployment types

- **Cloud-based** (public cloud): all in the cloud, migrated or newly built, for example moving data first, then building an app of virtual servers, databases and networking.
  - It scales well with little upfront cost, but alone cannot keep sensitive data on premises for compliance.
- **On-premises**: largely legacy IT plus virtualization and application management to try to lift utilization, missing many cloud benefits but offering dedicated resources and low latency.
- **Hybrid**: in-house and cloud resources together, for legacy systems kept in-house for maintenance or regulation.
  - Multi-cloud setups can also count as hybrid.
- Compliance shapes the choice but is not a deployment type.

## Key takeaways

- Definition, in order: (1) on-demand delivery (2) of IT resources (3) over the internet (4) with pay-as-you-go pricing.
- Deleting or deprovisioning a resource stops its charges at once.
- Cloud-based is all cloud and on-premises all in-house, while hybrid mixes them when some systems must stay on premises.

## Scenarios

- 2,000 TB in Amazon S3, deleted when unneeded: on-demand delivery and pay-as-you-go pricing.
- Regulated legacy apps on site, advanced analytics in the cloud: hybrid deployment.

## Terms

- **Cloud computing**: IT resources, on demand, over the internet, billed pay-as-you-go.
- **On-demand delivery**: resources within seconds, whenever needed.
- **Pay-as-you-go pricing**: paying only for what you consume.
- **Data center**: a server building with redundant power, cooling and security.
- **Co-location**: hosting in a shared facility.
- **Amazon Simple Queue Service**: the first public AWS infrastructure service.
- **Amazon S3**: the AWS data storage service.
- **Amazon Elastic Compute Cloud**: the AWS scalable compute service.
- **Cloud-based deployment**: everything in the cloud, also called public cloud.
- **On-premises deployment**: in-house resources, close to legacy IT.
- **Hybrid deployment**: in-house plus cloud resources.
- **Multi-cloud deployment**: left undefined, only said to count as hybrid.
