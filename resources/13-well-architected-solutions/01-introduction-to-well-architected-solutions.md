# Introduction to Well-Architected Solutions

## Objectives

- Preview the final services.
- See why designs need checking.

## Notes

### Design quality

- Next: development, business, end-user computing and IoT services.
- Building blocks allow almost any design, but is yours good?
- The AWS Well-Architected Framework, a leading AWS aid, tests if a design is functional, efficient, secure, built to last.

## Key takeaways

- Running does not mean well designed.
- Judge designs with the Framework.
- It is not the [WA Tool](03-aws-well-architected-framework.md).

## Terms

- **AWS Well-Architected Framework**: Best-practice guide for judging designs.
