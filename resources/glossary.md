# Glossary

Every term from the lessons' Terms sections, A to Z, with links to each lesson that defines it.

## A

- **Accelerated computing instances** ([Module 2, Amazon EC2 Instance Types](02-compute-in-the-cloud/02-amazon-ec2-instance-types.md)): EC2 instances with GPUs or other hardware accelerators.
- **Account Factory** ([Module 10, Governance](10-monitoring-compliance-and-governance/08-governance.md)): The AWS Control Tower part that creates each new account from one configurable template.
- **Agent callback** ([Module 13, Specialized Use Cases](13-well-architected-solutions/04-specialized-use-cases.md)): An Amazon Connect option that lets a caller hang up and get a call back from an agent instead of waiting on hold.
- **Aggregate bandwidth** ([Module 5, Global Architectures](05-networking/07-global-architectures.md)): The combined capacity of several AWS Direct Connect connections used together.
- **Agility** ([Module 4, Diving Deeper into AWS Global Infrastructure](04-going-global/03-diving-deeper-into-aws-global-infrastructure.md)): The ability to adapt quickly to change, such as by redeploying services fast.
- **Amazon API Gateway** ([Module 5, More Ways to Connect to the AWS Cloud](05-networking/03-more-ways-to-connect-to-the-aws-cloud.md)): A service for building and managing APIs.
- **Amazon AppStream 2.0** ([Module 13, AWS Specialized Services](13-well-architected-solutions/02-aws-specialized-services.md)): A service that streams desktop and SaaS apps to a browser on any device, so nothing is installed locally.
- **Amazon Athena** ([Module 8, Data Pipelines on AWS](08-ai-ml-and-data-analytics/07-data-pipelines-on-aws.md)): A serverless SQL service that queries data where it lives and bills per query.
- **Amazon Aurora** ([Module 7, Relational Database Services](07-databases/02-relational-database-services.md)): A high-throughput relational database compatible with MySQL and PostgreSQL.
- **Amazon Bedrock** ([Module 8, AWS Generative AI Solutions](08-ai-ml-and-data-analytics/05-aws-generative-ai-solutions.md)): A fully managed service that offers many foundation models from Amazon and other AI companies through one API.
- **Amazon CloudFront** ([Module 4, Diving Deeper into AWS Global Infrastructure](04-going-global/03-diving-deeper-into-aws-global-infrastructure.md); [Module 5, Global Networking](05-networking/06-global-networking.md)): The AWS content delivery network (CDN), which serves copies of content from edge locations close to users.
- **Amazon CloudWatch** ([Module 2, Scaling Amazon EC2](02-compute-in-the-cloud/06-scaling-amazon-ec2.md); [Module 10, Amazon CloudWatch](10-monitoring-compliance-and-governance/03-amazon-cloudwatch.md)): AWS's real-time monitoring service for resources and apps, whose metrics also drive scaling decisions.
- **Amazon Comprehend** ([Module 8, AWS AI/ML Solutions](08-ai-ml-and-data-analytics/03-aws-ai-ml-solutions.md)): A pre-built AI service that uses NLP to pull insights such as key phrases, language and sentiment from text.
- **Amazon Connect** ([Module 13, AWS Specialized Services](13-well-architected-solutions/02-aws-specialized-services.md)): An AI-powered cloud contact center for calls and chats, with call routing, recording and analytics.
- **Amazon Data Firehose** ([Module 8, Data Pipelines on AWS](08-ai-ml-and-data-analytics/07-data-pipelines-on-aws.md)): A fully managed service that ingests streaming data in near real time and delivers it to lakes, warehouses or analytics tools.
- **Amazon Data Lifecycle Manager** ([Module 6, Amazon Elastic Block Store (Amazon EBS) Data Lifecycle](06-storage/03-amazon-elastic-block-store-amazon-ebs-data-lifecycle.md)): A fully managed service whose policies automatically create, keep and delete EBS snapshots and EBS-backed AMIs.
- **Amazon Detective** ([Module 9, Detecting and Responding to Security Incidents](09-security/05-detecting-and-responding-to-security-incidents.md)): A service that uses ML and graph analytics to visually trace the root cause of a security issue.
- **Amazon DocumentDB (with MongoDB compatibility)** ([Module 7, Additional Database Services](07-databases/06-additional-database-services.md)): A fully managed, MongoDB-compatible document database.
- **Amazon DynamoDB** ([Module 7, NoSQL Database Services](07-databases/03-nosql-database-services.md)): AWS's fully managed, serverless NoSQL database.
- **Amazon EBS snapshot** ([Module 6, Amazon Elastic Block Store (Amazon EBS) Data Lifecycle](06-storage/03-amazon-elastic-block-store-amazon-ebs-data-lifecycle.md); [Module 10, AWS Trusted Advisor](10-monitoring-compliance-and-governance/10-aws-trusted-advisor.md)): A point-in-time, incremental backup of an EBS volume, stored in Amazon S3.
- **Amazon EC2 Auto Scaling** ([Module 2, Scaling Amazon EC2](02-compute-in-the-cloud/06-scaling-amazon-ec2.md)): A service that adds and removes EC2 instances automatically as demand changes.
- **Amazon EC2 Capacity Reservations** ([Module 2, Amazon EC2 Pricing](02-compute-in-the-cloud/05-amazon-ec2-pricing.md)): Compute capacity held for you in one Availability Zone at On-Demand rates.
- **Amazon EC2 instance store** ([Module 6, EC2 Instance Store and Amazon Elastic Block Store (Amazon EBS)](06-storage/02-ec2-instance-store-and-amazon-elastic-block-store-amazon-ebs.md)): Temporary block storage on the instance's host, lost when the instance stops or terminates.
- **Amazon ECR** ([Module 3, Containers and Orchestration on AWS](03-exploring-compute-services/03-containers-and-orchestration-on-aws.md)): AWS's fully managed container image registry.
- **Amazon ECS** ([Module 3, Containers and Orchestration on AWS](03-exploring-compute-services/03-containers-and-orchestration-on-aws.md)): AWS's streamlined, integrated container orchestration service.
- **Amazon EFS** ([Module 6, Amazon Elastic File System (Amazon EFS)](06-storage/07-amazon-elastic-file-system-amazon-efs.md)): A fully managed, elastic NFS file system for AWS and on-premises resources.
- **Amazon EKS** ([Module 3, Containers and Orchestration on AWS](03-exploring-compute-services/03-containers-and-orchestration-on-aws.md)): AWS's fully managed service for running Kubernetes clusters.
- **Amazon Elastic Block Store (Amazon EBS)** ([Module 2, Demo: Launching an Amazon EC2 Instance](02-compute-in-the-cloud/04-demo-launching-an-amazon-ec2-instance.md); [Module 6, EC2 Instance Store and Amazon Elastic Block Store (Amazon EBS)](06-storage/02-ec2-instance-store-and-amazon-elastic-block-store-amazon-ebs.md)): A managed service providing persistent block storage volumes, such as gp3, that act as an EC2 instance's disks.
- **Amazon Elastic Compute Cloud (Amazon EC2)** ([Module 1, What is Cloud Computing?](01-introduction-to-the-cloud/02-what-is-cloud-computing.md); [Module 2, Introduction to Amazon EC2](02-compute-in-the-cloud/01-introduction-to-amazon-ec2.md)): AWS's scalable compute service of on-demand, resizable virtual servers.
- **Amazon ElastiCache** ([Module 7, In-Memory Caching Services](07-databases/05-in-memory-caching-services.md); [Module 11, Cost Optimization](11-pricing-and-support/06-cost-optimization.md)): AWS's fully managed in-memory cache, which offloads frequent reads from a database.
- **Amazon EMR** ([Module 8, Data Pipelines on AWS](08-ai-ml-and-data-analytics/07-data-pipelines-on-aws.md)): A service for large-scale data processing on Apache frameworks such as Spark, Hadoop or Hive.
- **Amazon EventBridge** ([Module 2, Messaging and Queuing](02-compute-in-the-cloud/08-messaging-and-queuing.md)): A serverless event router between applications and services.
- **Amazon FSx** ([Module 6, Amazon FSx](06-storage/08-amazon-fsx.md)): A managed service that runs popular file systems, such as Windows File Server and Lustre, in AWS.
- **Amazon GuardDuty** ([Module 9, Detecting and Responding to Security Incidents](09-security/05-detecting-and-responding-to-security-incidents.md)): A service that continuously analyzes account and network activity to detect threats.
- **Amazon Inspector** ([Module 9, Detecting and Responding to Security Incidents](09-security/05-detecting-and-responding-to-security-incidents.md); [Module 10, AWS Trusted Advisor](10-monitoring-compliance-and-governance/10-aws-trusted-advisor.md)): A service that automatically scans workloads such as EC2, containers and Lambda for software vulnerabilities and ranks the findings by severity.
- **Amazon Kendra** ([Module 8, AWS AI/ML Solutions](08-ai-ml-and-data-analytics/03-aws-ai-ml-solutions.md)): An intent-aware enterprise search service that returns answers from company content rather than keyword hits.
- **Amazon Kinesis Data Streams** ([Module 8, Data Pipelines on AWS](08-ai-ml-and-data-analytics/07-data-pipelines-on-aws.md)): A serverless service that ingests streaming data in real time for several apps to read at once.
- **Amazon Lex** ([Module 8, AWS AI/ML Solutions](08-ai-ml-and-data-analytics/03-aws-ai-ml-solutions.md)): A service for adding lifelike voice or text conversation to apps.
- **Amazon Lightsail** ([Module 3, Additional Compute Services](03-exploring-compute-services/04-additional-compute-services.md)): Easy, budget-friendly and predictably priced AWS hosting for small sites.
- **Amazon Machine Image (AMI)** ([Module 2, Demo: Launching an Amazon EC2 Instance](02-compute-in-the-cloud/04-demo-launching-an-amazon-ec2-instance.md)): A prebuilt image holding an instance's OS, software and setup.
- **Amazon Macie** ([Module 9, Protecting Data](09-security/04-protecting-data.md)): A service that uses ML to discover sensitive data in Amazon S3.
- **Amazon Managed Blockchain** ([Module 7, Additional Database Services](07-databases/06-additional-database-services.md)): A service for building and running blockchain networks.
- **Amazon Neptune** ([Module 7, Additional Database Services](07-databases/06-additional-database-services.md)): A fully managed graph database.
- **Amazon OpenSearch Service** ([Module 8, Data Pipelines on AWS](08-ai-ml-and-data-analytics/07-data-pipelines-on-aws.md)): A service for searching, monitoring and analyzing business and operational data in real time.
- **Amazon Personalize** ([Module 8, AWS AI/ML Solutions](08-ai-ml-and-data-analytics/03-aws-ai-ml-solutions.md)): A service that makes per-customer recommendations from historical data.
- **Amazon Polly** ([Module 8, AWS AI/ML Solutions](08-ai-ml-and-data-analytics/03-aws-ai-ml-solutions.md)): A service that turns text into lifelike speech.
- **Amazon Q** ([Module 8, Introduction to Generative AI on AWS](08-ai-ml-and-data-analytics/04-introduction-to-generative-ai-on-aws.md)): A generative AI assistant tailored to a business and tied to its company data.
- **Amazon Q Business** ([Module 8, AWS Generative AI Solutions](08-ai-ml-and-data-analytics/05-aws-generative-ai-solutions.md)): The Amazon Q assistant that answers questions, solves problems and runs tasks from company data.
- **Amazon Q Developer** ([Module 8, AWS Generative AI Solutions](08-ai-ml-and-data-analytics/05-aws-generative-ai-solutions.md)): The Amazon Q coding assistant that suggests code, up to whole functions, in multiple IDEs.
- **Amazon QuickSight** ([Module 8, Data Pipelines on AWS](08-ai-ml-and-data-analytics/07-data-pipelines-on-aws.md)): A business intelligence service for building interactive dashboards and reports.
- **Amazon RDS** ([Module 7, Relational Database Services](07-databases/02-relational-database-services.md)): AWS's managed relational database service, which automates upkeep such as patches and backups.
- **Amazon Redshift** ([Module 8, Data Pipelines on AWS](08-ai-ml-and-data-analytics/07-data-pipelines-on-aws.md)): A managed data warehouse for structured or semistructured data at petabyte scale.
- **Amazon Rekognition** ([Module 8, AWS AI/ML Solutions](08-ai-ml-and-data-analytics/03-aws-ai-ml-solutions.md)): A service that analyzes images and video for people, objects, scenes, activities and text.
- **Amazon Route 53** ([Module 4, Diving Deeper into AWS Global Infrastructure](04-going-global/03-diving-deeper-into-aws-global-infrastructure.md); [Module 5, Global Networking](05-networking/06-global-networking.md)): The highly available, scalable AWS DNS service, which maps domain names to IP addresses.
- **Amazon S3** ([Module 1, What is Cloud Computing?](01-introduction-to-the-cloud/02-what-is-cloud-computing.md); [Module 6, Amazon Simple Storage Service (Amazon S3)](06-storage/04-amazon-simple-storage-service-amazon-s3.md)): AWS's fully managed object storage service for virtually unlimited data.
- **Amazon S3 Access Points** ([Module 6, Amazon Simple Storage Service (Amazon S3)](06-storage/04-amazon-simple-storage-service-amazon-s3.md)): A feature that gives each group its own access policy on a shared dataset.
- **Amazon S3 Audit Logs** ([Module 6, Amazon Simple Storage Service (Amazon S3)](06-storage/04-amazon-simple-storage-service-amazon-s3.md)): Logs of every request made to S3 resources.
- **Amazon S3 File Gateway** ([Module 6, AWS Storage Gateway](06-storage/09-aws-storage-gateway.md)): A Storage Gateway type that offers a local file share whose files are stored in Amazon S3.
- **Amazon S3 Object Lambda** ([Module 11, AWS Pricing Concepts](11-pricing-and-support/02-aws-pricing-concepts.md)): An S3 data processing feature that carries its own charge.
- **Amazon S3 Outposts** ([Module 6, Amazon S3 Storage Classes and S3 Lifecycle](06-storage/05-amazon-s3-storage-classes-and-s3-lifecycle.md)): S3 storage delivered on premises through AWS Outposts.
- **Amazon SageMaker AI** ([Module 8, AI/ML on AWS](08-ai-ml-and-data-analytics/02-ai-ml-on-aws.md)): A fully managed service for building, training and deploying your own ML models while AWS runs the infrastructure.
- **Amazon SageMaker JumpStart** ([Module 8, AWS Generative AI Solutions](08-ai-ml-and-data-analytics/05-aws-generative-ai-solutions.md)): A model hub in SageMaker AI for fine-tuning and deploying pre-trained solutions in a few clicks.
- **Amazon SES** ([Module 13, AWS Specialized Services](13-well-architected-solutions/02-aws-specialized-services.md)): A scalable email service that apps use to send reliable bulk email.
- **Amazon Simple Notification Service (Amazon SNS)** ([Module 2, Messaging and Queuing](02-compute-in-the-cloud/08-messaging-and-queuing.md); [Module 10, Amazon CloudWatch](10-monitoring-compliance-and-governance/03-amazon-cloudwatch.md)): A publish-subscribe service that pushes messages to topic subscribers, such as the texts a CloudWatch alarm sends.
- **Amazon Simple Queue Service (Amazon SQS)** ([Module 1, What is Cloud Computing?](01-introduction-to-the-cloud/02-what-is-cloud-computing.md); [Module 2, Messaging and Queuing](02-compute-in-the-cloud/08-messaging-and-queuing.md)): A queue service that reliably holds messages between components, and the first public AWS infrastructure service.
- **Amazon Textract** ([Module 8, AWS AI/ML Solutions](08-ai-ml-and-data-analytics/03-aws-ai-ml-solutions.md)): A service that extracts typed or handwritten text from documents, forms and tables.
- **Amazon Transcribe** ([Module 8, AWS AI/ML Solutions](08-ai-ml-and-data-analytics/03-aws-ai-ml-solutions.md)): A service that converts speech to text.
- **Amazon Translate** ([Module 8, AWS AI/ML Solutions](08-ai-ml-and-data-analytics/03-aws-ai-ml-solutions.md)): A service for live or batch text translation.
- **Amazon Virtual Private Cloud (Amazon VPC)** ([Module 5, Introduction to Networking](05-networking/01-introduction-to-networking.md)): An isolated slice of the AWS Cloud with a virtual network you define.
- **Amazon WorkSpaces** ([Module 13, AWS Specialized Services](13-well-architected-solutions/02-aws-specialized-services.md)): Fully managed, persistent cloud desktops that staff reach securely from anywhere.
- **Amazon WorkSpaces Secure Browser** ([Module 13, AWS Specialized Services](13-well-architected-solutions/02-aws-specialized-services.md)): A lightweight managed browser that lets web-only users safely reach private sites and SaaS apps with no client software.
- **ap-southeast-1** ([Module 1, Applying Cloud Concepts to Real Life Use Cases](01-introduction-to-the-cloud/06-applying-cloud-concepts-to-real-life-use-cases.md)): The code of the Singapore Region, as given in the course video.
- **API (application programming interface)** ([Module 2, How to Provision AWS Resources](02-compute-in-the-cloud/03-how-to-provision-aws-resources.md); [Module 5, More Ways to Connect to the AWS Cloud](05-networking/03-more-ways-to-connect-to-the-aws-cloud.md)): A predefined way for software systems to interact, used to manage AWS resources programmatically.
- **Application Load Balancer** ([Module 5, Global Networking](05-networking/06-global-networking.md)): A load balancer that, in the course's global networking example, passes requests from CloudFront to EC2 instances.
- **Artificial intelligence (AI)** ([Module 8, Introduction to AI and Machine Learning](08-ai-ml-and-data-analytics/01-introduction-to-ai-and-machine-learning.md)): Computer systems that perform humanlike tasks.
- **Assess phase** ([Module 12, Introduction to Migration](12-migrating-to-the-aws-cloud/01-introduction-to-migration.md)): The first migration phase, which checks readiness and builds the business case.
- **Auditing** ([Module 10, Introduction to Monitoring, Compliance, and Governance in the AWS Cloud](10-monitoring-compliance-and-governance/01-introduction-to-monitoring-compliance-and-governance-in-the-aws-cloud.md)): Periodic review that checks whether controls work.
- **Aurora Replica** ([Module 7, Relational Database Services](07-databases/02-relational-database-services.md)): One of up to 15 copies in an Aurora cluster that traffic can fail over to.
- **Authentication** ([Module 9, Introduction to Security on AWS](09-security/01-introduction-to-security-on-aws.md)): Proving identity with credentials.
- **Authorization** ([Module 9, Introduction to Security on AWS](09-security/01-introduction-to-security-on-aws.md)): Deciding what an authenticated identity may do.

- **Auto Scaling group** ([Module 2, Scaling Amazon EC2](02-compute-in-the-cloud/06-scaling-amazon-ec2.md)): A group of EC2 instances scaled together between set limits.
- **Automated remediation** ([Module 10, Auditing AWS Resources for Compliance](10-monitoring-compliance-and-governance/06-auditing-aws-resources-for-compliance.md)): Automatic fixes that bring noncompliant resources back into compliance.
- **Availability Zone (AZ)** ([Module 1, Introduction to AWS Global Infrastructure](01-introduction-to-the-cloud/04-introduction-to-aws-global-infrastructure.md)): An isolated location within a Region, made up of one or more data centers.

- **AWS AI/ML stack** ([Module 8, AI/ML on AWS](08-ai-ml-and-data-analytics/02-ai-ml-on-aws.md)): AWS's three tiers of AI/ML offerings: AI services, ML services, and ML frameworks and infrastructure.

- **AWS Application Discovery Service** ([Module 12, Migration Services and Tools](12-migrating-to-the-aws-cloud/04-migration-services-and-tools.md)): A service that inventories on-premises servers and their connections.
- **AWS Application Migration Service** ([Module 12, Migration Services and Tools](12-migrating-to-the-aws-cloud/04-migration-services-and-tools.md)): A service that moves applications to AWS and can modernize them.
